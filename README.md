# Morse Code Translator 🔠

A simple and interactive Morse Code Translator built with Python.

This program allows users to translate English text into Morse Code and decode Morse Code back into English through a command-line interface.

### Features
- **Text to Morse:** Converts English letters into their corresponding Morse Code sequences.
- **Morse to Text:** Decodes Morse Code into readable English text.
- **Interactive CLI:** Easy-to-use menu system.
- **Input Handling:** Basic input validation and error handling.
- **Modular Design:** Uses a dedicated translation function for both conversion directions.

### Technologies Used
- Python
- Lists
- Strings
- Functions
- Conditional Statements
- Loops
- List Indexing

### How to Run
```bash
python main.py
```

### Usage
1. Select a conversion mode.
2. Enter your text or Morse Code.
3. Get the translated result.
4. Choose Quit to exit the program.

**A beginner-friendly Python project focused on string manipulation, indexing, and logical problem-solving.**
